# ML_user-churn-prediction
# Прогнозирование оттока клиентов телеком-оператора (Telco Customer Churn)

Реализация модели машинного обучения для предсказания оттока пользователей оператора связи на основе исторических данных IBM с платформы Kaggle. Проект ориентирован на удержание клиентов и оптимизацию маркетингового бюджета.

##  1. Бизнес-контекст и задача
Высокая конкуренция на рынке телекоммуникаций приводит к постоянной миграции пользователей между операторами. Стоимость удержания текущего клиента (Retention Cost) значительно ниже стоимости привлечения нового (CAC). 

Бизнес-цель: создать ML модель, выявляющую пользователей с высоким риском ухода, для последующего проведения таргетированных маркетинговых кампаний (специальные тарифы, скидки, бонусы).
Критерий успеха: повышение метрики Recall при фиксированном уровне Precision (более 70%), чтобы минимизировать пропуск «уходящих» клиентов без чрезмерных затрат на удержание лояльной аудитории.

## 2. Анализ данных и ключевые инсайты (EDA)
Исходный датасет содержит информацию о 7043 клиентах и 21 признаке. 
Клиентах, которые ушли в течение последнего месяца – колонка Churn

Услуги, на которые подписан каждый клиент - телефон (PhoneService), несколько линий (MultipleLines), тип интернет-подключения (InternetService), онлайн-безопасность (OnlineSecurity), онлайн-резервное копирование (OnlineBackup), защита устройств (DeviceProtection), техническая поддержка (TechSupport), потоковое телевидение (StreamingTV), фильмы (StreamingMovies)

Информация об учетной записи клиента - продолжительность сотрудничества (tenure), тип контракта (Contract), способ оплаты (PaymentMethod), безбумажное выставление счетов (PaperlessBilling), ежемесячные платежи (MonthlyCharges) и общие расходы (TotalCharges)

Соц-демографическая информация о клиентах – пол (gender), возрастной диапазон (SeniorCitizen), есть ли партнеры (Partner) и иждивенцы (Dependents)
